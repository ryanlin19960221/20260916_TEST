# Ryan Lin · Personal Timepiece & Space

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A minimalist personal website built with a serene **Nordic Modern Light** aesthetic. It features a real-time digital clock, full calendar date display, detected local timezone indicator, dynamic greeting, and seamless connection to GitHub Project #1.

## ✨ Features
- **Nordic Modern Light Design**: Soft frosted glass cards (`backdrop-filter`), diffused multi-layered shadows, and gentle ambient light mesh.
- **Precision Live Clock**: Zero-jitter tabular numerals, blinking separator, dedicated seconds counter, and 12H/24H format switcher.
- **Personalized Profile**: Interactive click-to-edit name with persistent `localStorage` storage and dynamic avatar initial.
- **GitHub Connected Card**: Direct quick-access link to [GitHub Project #1](https://github.com/users/ryanlin19960221/projects/1) and profile [@ryanlin19960221](https://github.com/ryanlin19960221).
- **Timezone & Date**: Automatic local IANA timezone detection with GMT offset calculation.

## 🚀 Getting Started

Simply open `index.html` in any modern web browser, or serve locally with Python:

```bash
python -m http.server 5173
```

Visit: `http://localhost:5173`
